実写版『モアナと伝説の海』でマウイを演じ、製作にも参加したドウェイン・ジョンソンの歩みと韓国での興行記録を整理します。

SS.Desk Globalドウェイン・ジョンソン

モアナと伝説の海

韓国公開19日目もデイリー3位

ディズニーの実写版『モアナと伝説の海』は2026年7月8日に韓国で公開されました。韓国映画振興委員会の7月26日集計を引用した原記事によると、同日の順位は3位、観客数は3万4,802人です。公開19日目の一日を示す記録で、最終的な興行結果とは分けて考える必要があります。ドウェイン・ジョンソンは本作でマウイを演じるだけでなく、製作にも参加しました。

ディズニーが7月9日に公開した公式インタビューでは、マウイを再び演じる過程と新曲「Along the Way」の録音について本人が説明しています。アニメーションで声から作った人物を、実際のセットで表情と身体を使って表現し、音楽と製作にも関わりました。同じ俳優が媒体の変化に合わせ、何を残して何を調整したのかを見ることができます。

アニメーションのリズムを身体へ

マウイは変身する力と大きな釣り針を持つ半神です。ジョンソンは2016年のアニメーション『モアナと伝説の海』と2024年の『モアナと伝説の海2』で声を担当し、今回の実写版では本人が同じ人物を演じました。力強さだけでなく、モアナと衝突し、冗談を交わしながら航海を助ける仲間としての表情も重要です。声で作ってきたテンポを、視線や姿勢、動きへ広げる必要があります。

注目点は、アニメーションをそのまま再現できたかどうかだけではありません。豪快なユーモアを保ちながら、実写画面に合う温度を作れるかが大切です。二つのアニメーション作品で築いた話し方や歌の感覚は強い土台ですが、カメラの前では言葉の間の小さな動きも見えます。製作への参加も含めると、今回は同じ役の反復というより、別の形式に合わせてキャラクターを組み直す仕事として捉えられます。

リングから映画、そして製作へ

ジョンソンは1972年5月2日生まれで、2026年7月27日時点で54歳です。1996年のWWEサバイバー・シリーズでプロレスラーとしてデビューし、2001年の『ハムナプトラ2／黄金のピラミッド』から映画へ進みました。リングで培った強い存在感、身体の制御、観客の反応を読む速さは、アクションとコメディの両方で生かされています。WWE公式プロフィールでは、WWE王座を8度獲得したと記録されています。

映画では『スコーピオン・キング』、『ワイルド・スピード』シリーズ、『ジュマンジ』シリーズ、『ジャングル・クルーズ』、『ブラックアダム』などに出演しました。Seven Bucks Productionsを設立して映画とテレビの製作も続け、2026年にはDisney Legendsの一人に選ばれました。声優、実写俳優、歌、製作という複数の活動が『モアナと伝説の海』で交差しています。親しまれてきたマウイの背後にある仕事の広がりを見ると、ジョンソンの現在地がよりはっきりします。
